# Remindly

A reminder app with natural language input. Write tasks the way you talk, Remindly handles the rest.

## Features

- Natural language input in Indonesian and English
- Automatic detection of date, time, category, and priority
- Push notifications before tasks are due
- Weekly calendar view
- Today and upcoming task views
- Completed task history
- Offline support (PWA)
- Bilingual: Indonesian and English

## Tech Stack

- React 18
- Vite
- Tailwind CSS
- Dexie (IndexedDB)
- Vite Plugin PWA

## Requirements

- Node.js 18 or higher
- npm 9 or higher

## Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/your-username/remindly.git
cd remindly
npm install
```

## Development

Start the local development server:

```bash
npm run dev
```

The app will be available at `http://localhost:5173`.

## Build

Build the app for production:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
